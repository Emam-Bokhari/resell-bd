# ReSellBD

<p>
  <strong>A modern marketplace platform for buying and selling pre-owned products.</strong>
</p>

<p>
ReSellBD is a full-stack eCommerce platform that allows users to securely buy and sell second-hand products. The application provides a smooth user experience for product browsing, searching, listing, and order management.
</p>

<p>
This repository is organized as a monorepo, containing both the frontend and backend applications.
</p>

## ✨ Features

- 🔐 **User Authentication & Authorization** — Secure login, registration, and role-based access control
- 🛒 **Buy & Sell Pre-Owned Products** — List items for sale or browse and purchase from others
- 🗂️ **Product Categories & Search** — Easily find products with category filters and search
- ❤️ **Wishlist Management** — Save favorite products for later
- 🧺 **Shopping Cart** — Add multiple items and manage your cart
- 💳 **Secure Checkout** — Safe and streamlined checkout process
- 📦 **Order Management** — Track and manage orders from placement to delivery
- 👤 **User Dashboard** — Personalized dashboard for buyers and sellers
- ⭐ **Product Reviews & Ratings** — Community-driven product feedback
- 🖼️ **Image Upload** — Cloudinary-powered product image management
- 🛠️ **Admin Management** — Comprehensive admin panel for platform oversight
- 🌐 **RESTful API** — Clean, scalable API design
- 📱 **Responsive User Interface** — Optimized for all screen sizes

## 📦 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [MongoDB](https://www.mongodb.com/)
- [Redis](https://redis.io/)

### Clone the Repository

```bash
git clone https://github.com/Emam-Bokhari/resell-bd.git
cd ReSellBD
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

The frontend will be available at `http://localhost:3000`

### Backend Setup

```bash
cd server
npm install
npm run dev
```

The backend API will be available at `http://localhost:5000`
